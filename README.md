# Pinduoduo Uzbekistan

Cross-border e-commerce platform for Uzbekistan.

## Structure

- frontend/ — customer-facing applications
- backend/ — API and business logic
- docs/ — product and architecture documentation
- infra/ — infrastructure/deployment configuration
- tests/ — integration and end-to-end tests
- .github/workflows/ — CI/CD

## Security

Never commit secrets, tokens, passwords, private keys or production credentials. Use local .env files or a secret manager.
